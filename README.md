## 🛠️ Instructions Followed
1. **HTML and CSS Separated**: All assignments maintain strict separation between `.html` markup and external `.css` stylesheets.
2. **Semantic Hierarchy**: Extensive use of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`.
3. **Responsive Design**: Designed with mobile-first principles, CSS Flexbox, and CSS Grid.
4. **No External JavaScript Dependencies Required**: All state transitions and interactive elements are built with clean CSS transitions and pseudo-classes.
